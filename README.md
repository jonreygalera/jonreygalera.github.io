# Privacy Policies

This repository contains the privacy policies for applications developed by [Jon Rey Galera](https://jonreygalera.vercel.app).

## 📂 Project Structure

- **[say_mate/](say_mate/)**: Contains the privacy policy for the **SayMate** AAC app.
  - `privacy-policy.html`: The main privacy policy document.
  - `saymate_logo.webp`: Brand assets for the policy page.
  - `favicon.ico`: Page icon.

## 🚀 Features

- **Professional Design**: Modern HTML5 and CSS3 styling with the [Inter](https://fonts.google.com/specimen/Inter) font.
- **Brand Consistent**: Matching color palettes (e.g., Soft Teal for SayMate).
- **Responsive**: Fully optimized for mobile, tablet, and desktop viewports.
- **Accessible**: Semantic HTML structure for screen readers and search engines.

## 🛠 Maintenance

To update a privacy policy:
1. Navigate to the specific app folder (e.g., `say_mate/`).
2. Modify the `privacy-policy.html` file.
3. Ensure the "Last Updated" date at the top of the file is updated.

## 🌐 Deployment

These policies are designed to be hosted via static site hosting services like GitHub Pages or Vercel.
